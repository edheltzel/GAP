# WriteChapter Workflow

Transform confirmed story beats into a revisable prose draft while preserving writer ownership and project continuity.

## Preflight

1. Require the writer to confirm the project directory, target chapter or scene, and desired output location.
2. Stop when any required path or target is missing or ambiguous.
3. Require `story-bible.md` or equivalent writer-confirmed beat input.
4. Read `story-bible.md` in full before drafting.
5. Read every existing target draft in full before updating it.
6. Confirm whether the writer wants chat-only prose, a new file, or an update to an existing file.
7. Treat retained material outside the confirmed project as optional and read-only.

Do not create a directory or select a filename without confirmation. Do not overwrite writer prose wholesale.

## 1. Load Beat Context

For each target beat, extract:

- meaning and thematic work;
- character pressure and change;
- plot event, cause, and consequence;
- mystery questions, plants, and reveals;
- world details that affect the action;
- relationship movement;
- prose register and aesthetic constraints.

Stop and ask when required beat information is open or contradictory.

## 2. Plan Scenes

For each scene, record point of view, goal, conflict, turn, outcome, and the seven-layer articulation. Use `PhasesAndEvents.md` and `StoryStructures.md` only as optional scaffolding.

## 3. Plan Voice and Rhetoric

Read `AestheticProfiles.md` and `RhetoricalFigures.md`. Identify a small number of high-impact moments for deliberate rhetorical craft. Keep dialogue distinct by vocabulary, rhythm, avoidance patterns, and subtext.

## 4. Draft

Write from the confirmed scene plan:

- filter description through the point-of-view character;
- show emotion through behavior and concrete detail;
- preserve causal clarity;
- vary sentence length deliberately;
- use specific details that serve more than setting;
- keep every new invention within the writer-approved boundaries.

The draft is a proposal the writer owns and may redirect.

## 5. Freshness and Layer Checks

Apply `AntiCliche.md`. Confirm each planned layer landed naturally. Remove generic phrasing, decorative world detail, unexplained continuity changes, and rhetorical devices that feel forced.

## 6. Critic Passes

Read `Critics.md`. Run focused passes for layer completeness, rhetoric, freshness, reader experience, continuity, pacing, and voice as appropriate. Critics return actionable observations; they do not replace the writer's decisions.

## 7. Preserve Existing Work

When updating an existing draft:

1. Re-read it immediately before editing.
2. Change only the agreed chapter or scene range.
3. Preserve unrelated writer material.
4. Report what changed.

## 8. Continuity Follow-up

If drafting reveals a proposed continuity change, do not silently update it. Present the proposal first. After writer approval, re-read `story-bible.md`, update only the affected sections or checklist items, and add a change-log entry.

## Output

Return:

1. the prose draft or confirmed file path;
2. the layers advanced;
3. critic findings and applied changes;
4. proposed continuity updates, if any;
5. unresolved questions;
6. a recommendation for the next scene or revision pass.
