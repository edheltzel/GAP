# Revise Workflow

Improve existing story content while preserving the writer's voice, confirmed continuity, and original material.

## Preflight

1. Require the writer to confirm the project directory and exact draft to revise.
2. Stop when either path is missing or ambiguous.
3. Read the draft in full.
4. Read `story-bible.md` in full before continuity-sensitive revision.
5. Ask what kind of revision is wanted and whether direct file edits are authorized.
6. Treat other retained material as optional and read-only.

Never overwrite the source draft without explicit authorization. When authorization is limited to suggestions, return a patch plan or quoted alternatives only.

## Revision Types

- **Polish:** Tighten verbs, rhythm, specificity, and redundant language.
- **Deepen:** Strengthen an underserved narrative layer through action or behavior.
- **Restructure:** Reorder, remove, or add scenes to improve causality and pacing.
- **Voice:** Restore narrator and character voice consistency.
- **Freshness:** Apply `AntiCliche.md` and replace generic language.
- **Rhetoric:** Apply selected devices from `RhetoricalFigures.md` at high-impact moments.

## Procedure

1. Record what already works and must remain intact.
2. Compare the draft with the relevant beat, character, mystery, world, relationship, and prose sections in `story-bible.md`.
3. Propose the smallest revision that satisfies the request.
4. Preserve writer-authored lines unless the revision specifically targets them.
5. Mark newly offered language as a proposal until accepted.
6. Check continuity, causal flow, voice, information state, and freshness after revision.

## Continuity Updates

If an accepted revision changes story facts or structure:

1. Re-read `story-bible.md` before the update.
2. Update only affected sections and checklist items.
3. Preserve unrelated writer material.
4. Add a change-log entry describing the writer-approved change.

If no continuity fact changed, do not edit `story-bible.md`.

## Output

Return:

- the revised passage or suggested alternatives;
- a concise change summary;
- continuity checks performed;
- any proposed `story-bible.md` updates;
- unresolved writer decisions.
