# Webdesign

Webdesign implements interfaces directly in the target codebase through `Workflows/DirectDesign.md`.

## Supported route

1. Read `References/FrontendDesignPhilosophy.md`.
2. Inspect the target project's framework, components, tokens, and typography.
3. Declare an aesthetic register and output contract.
4. Implement production-grade code that preserves existing project conventions.
5. Verify with `/opt/homebrew/bin/chrome-devtools-axi` at desktop and mobile widths.
6. Return changed files and browser evidence.

Historical design-canvas and handoff-bundle documents remain for reference only. Their former runtime and command paths are unavailable and are not part of current routing.
