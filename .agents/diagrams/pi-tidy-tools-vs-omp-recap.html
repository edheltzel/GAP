Two projects · one workflow question

Pi Tidy Tools
vs. Oh My Pi

OMP already covers glanceable tool execution and return-from-break recaps. Pi Tidy Tools remains distinctly useful inside Pi for its stricter one/two-line cards and exact last-turn /diff.

Practical verdict
Use both—inside their own runtimes.

Do not install the Pi extension expecting it to improve OMP. OMP’s native recap is already enabled on this machine.

Do not mix the three layers

Display

What you see

Tool cards, expansion, idle recap, transcript export.

  • Ctrl+O
  • /btw
  • /dump
Active context

What the model sees

Current messages plus compaction products. Inspect token pressure with /context.

  • /compact rewrites context
  • /shake removes heavy payloads
Durable memory

What survives sessions

Hindsight or configured memory banks. Useful for project knowledge, not a substitute for a current-session recap.

  • retain
  • recall
  • reflect
04

The context-loss bug is separate

Recap does not clear session context.

The idle recap runs as an ephemeral side-channel and only paints a status line. The strongest open true-context-loss match is OMP issue #4090: after multiple compactions, branching or rewinding can select an older compaction whose preserved archive was destructively elided. The closest outstanding recovery PR is #5168, which repairs interrupted session tails on resume. Neither is the recap feature itself.
