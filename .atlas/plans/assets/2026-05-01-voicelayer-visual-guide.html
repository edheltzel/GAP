VoiceLayer · Quick Reference · 2026-05-01

MCP voice server for Claude Code Press F6, speak, ship.

VoiceLayer is local-first voice I/O wired into Claude Code via MCP. You speak at ~150 wpm versus typing at ~40 wpm — that's the speed advantage. Whisper transcribes locally; only the spoken text leaves the box (to edge-tts). Already installed and running on this Mac — this page is a reference, not a setup guide.

02 · Tools you'll actually use

Two of the eleven do the heavy lifting

Non-blocking

voice_speak

Fire and forget · TTS only

Claude announces something out loud and keeps working. No pause, no answer expected.

Speech rate auto-adjusts by mode: announce +10%, brief −10%, long text auto-slows so you can follow.

Blocking

voice_ask

Question → answer · TTS + STT

Claude speaks the question, records you, transcribes locally via whisper.cpp, returns the text.

Claude waits for your answer before doing anything else. ~300ms transcription latency on Apple Silicon.

11 tools total in the MCP — the rest cover lifecycle, voice cloning, and bar customization. Stick with these two.

03 · Five modes

Pick the cadence to match the task

ANNOUNCE
Fast, declarative. Best for alerts and status pings.
BRIEF
Slower, optimized for clarity over speed.
CONSULT
Balanced back-and-forth — short questions, short answers.
CONVERSE
Continuous natural dialogue with full pacing.
THINK
Extended thinking, deliberate pacing for hard problems.
Each mode auto-adjusts speech rate, silence-detection timeout (0.5s quick / 1.5s standard / 2.5s thoughtful), and interaction pattern. Pick once, forget about it.
04 · How it's wired

The components on this Mac

ComponentDetail
MCP server bunx voicelayer-mcp — registered in .mcp.json at the user scope
STT engine whisper.cpp via brew · model at ~/.cache/whisper/ggml-large-v3-turbo.bin
TTS engine edge-tts (Microsoft cloud, free) — only the text to speak leaves the box; voice and transcripts never leave
Audio player afplay · macOS native, no overlap with prior speech
VAD Silero VAD · silence detection 0.5s quick / 1.5s standard / 2.5s thoughtful
State dir ~/.local/state/voicelayer/ — session tokens, lockfile mutex (one mic at a time)
Manual stop touch ~/.local/state/voicelayer/stop-{token} — kills an in-flight recording from another shell
05 · Why we switched

VoiceMode → VoiceLayer // 2026-04-04

Before · what was broken

VoiceMode

mbailey/voicemode v8.5.1
  • No signal handlers — couldn't shut down cleanly
  • Dead cleanup_on_shutdown() code path
  • Orphaned MCP server processes (~141MB each)
  • Kokoro-FastAPI backend with PyTorch memory leak (~200MB/hour)
  • Per-session MCP load = N copies of voicemode in memory at once
After · why this won

VoiceLayer

EtanHey/voicelayer
  • TypeScript / Bun — matches the rest of the stack
  • Real converse tool — not just speak/listen primitives
  • Silero VAD for proper silence detection
  • Session mutex (lockfile) — two sessions can't grab the mic at once
  • Proper signal handlers — clean shutdown every time
  • Singleton daemon on Unix socket — all Claude sessions share one process, no orphans by design
  • Scored 13/21 vs voicemode's feature set after surveying 80+ MCP voice projects

06 · Install reference

For when you rebuild this Mac

›  Show one-shot install commands already done 
# 1 · System dependencies (audio + STT)
brew install sox whisper-cpp

# 2 · TTS provider (cloud, free)
pip3 install edge-tts

# 3 · Whisper model (1.5 GB — large-v3-turbo)
mkdir -p ~/.cache/whisper
curl -L -o ~/.cache/whisper/ggml-large-v3-turbo.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo.bin

# 4 · VoiceLayer MCP (Bun-installed, runs as daemon)
bun add -g voicelayer-mcp

# 5 · Register with Claude Code at user scope
claude mcp add --scope user voicelayer -- bunx voicelayer-mcp
