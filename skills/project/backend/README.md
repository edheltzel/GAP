# Backend

Backend engineering - Effect (TypeScript) services and code, and review for Effect, Go, Python, and Rust.

## Installation

Every skill in this group:

```bash
npx skills add https://github.com/edheltzel/Do-Skills/tree/master/skills/project/backend
```

One skill by exact name:

```bash
npx skills add edheltzel/Do-Skills --skill=<skill-name>
```
