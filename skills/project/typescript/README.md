# TypeScript

Language-wide TypeScript - standards, refactoring, and type-driven design. Install alongside frontend, backend, or tooling.

## Installation

Every skill in this group:

```bash
npx skills add https://github.com/edheltzel/Do-Skills/tree/master/skills/project/typescript
```

One skill by exact name:

```bash
npx skills add edheltzel/Do-Skills --skill=<skill-name>
```
