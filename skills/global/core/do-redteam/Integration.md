# Integration

## do-first-principles

Before parallel analysis, use `do-first-principles`, if installed.

- Deconstruct the argument into its parts (that skill's Deconstruct step).
- Challenge stated constraints and class each as hard, soft, or an assumption (that skill's Challenge step).

The sharpest critique usually comes from a hidden assumption, not a surface objection.

## Output

Steelman and counter-argument, each 8 numbered points, 12-16 words per point. Direct. Include where the attacks converged. Attack the real argument, not a strawman. Skip nits and generic objections.
