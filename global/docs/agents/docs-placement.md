# Docs vs code placement

## Rules

- Code lives with the product; durable agent/process docs live where the project (or this home tree) says.
- Handoffs: follow the repo's AGENTS/DOX location; never stash them only in `/tmp` or harness install dirs.
- Long-running work may use a `PLANS.md` (or project equivalent) so intent stays git-auditable.
- Prefer git-auditable notes over opaque auto-memory for decisions that must survive sessions.

## Done

Artifacts are where the next agent will look, not where it was convenient to dump them.
