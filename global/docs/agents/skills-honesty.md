# Skills honesty

## Rules

- Do not invent harness skills, slash commands, MCP tools, or APIs that are not installed.
- Prefer extending a real owner over a parallel fake skill.
- Before dynamic workflows, ultra code, or mass parallel agents, explain tradeoffs and get explicit approval.
- If a skill name is unknown, say so - do not improvise a plausible one.

## Done

Every tool or skill you named exists on the machine or you flagged it as missing.
