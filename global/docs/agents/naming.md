# Naming / completeness sweeps

## Rules

- Names match existing project vocabulary (commands, packages, env keys).
- When renaming, sweep callers, docs, tests, and install scripts in the same change when practical.
- Prefer boring, searchable names over clever ones.
- Do not leave half-renames or dual names without a deprecation path.

## Done

A quick ripgrep-style sweep found no stale names in the blast radius you claimed.
